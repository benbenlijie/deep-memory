## Product requirements to test coverage matrix

Coverage levels used below:

- Unit/API: direct Python API or helper behavior.
- CLI: Typer command behavior and output/error behavior.
- MCP: Python functions registered as MCP tools; not a live client transport unless stated.
- Adapter: Hermes/Codex wrapper behavior.
- WebUI: local inspector helper/render behavior.
- Eval: checked-in benchmark/eval fixture.
- Docs/spec: documented guarantee without complete executable coverage.

## Gap-to-regression backlog

These are the highest-value tests to add next, each directly derived from the matrix above:

1. Privacy false-negative fixtures: private key headers, bearer tokens, auth cookies, multiline `.env` values.
2. Privacy false-positive fixtures: benign `passwordless`/`secretless`/redacted examples and documentation snippets that must not be rejected.
3. Hermes CLI malformed JSONL atomicity: good first line + malformed second line leaves DB empty and prints line number.
4. Live stdio MCP schema smoke: list tools, call invalid params, assert error shape and no DB mutation.
5. CLI search lifecycle output: deprecated/superseded records hidden by default and visible only through explicit flags once machine-readable search output is stable.
6. Backup restore drill: restore a generated backup to a new DB and verify record counts/IDs against the manifest.
7. WebUI route/browser smoke: edit/delete through the served local UI rather than helper functions only.
8. Cross-agent runtime smoke: real wrapper invocation per adapter, with command transcript and resulting DB provenance rows.

## Boundaries / non-claims

- This matrix records current alpha guarantees; it does not claim hosted sync, full vector retrieval, every-agent native adapters, or adversarial DLP completeness.
- WebUI coverage is MVP helper/render coverage plus spec, not a full UX/a11y audit.
- MCP coverage is direct Python tool-function coverage plus docs, not yet a live multi-client interoperability suite.
- Privacy policy is conservative pattern gating; it reduces obvious mistakes but is not a complete secret scanner.
